XM / MOD / S3M / IT → DMM + DMI

Перетащи модули сюда
или выбери файлы
.xm .mod .s3m .it
Если каналов больше 8

Рядом с .dmm пишутся .dmi. Формат DMM — 8 каналов, частота ноты не выше 65535 Гц, нота не переносится через границу паттерна.

DMM / WAD → XM

Перетащи .dmm, .dmi или .wad
.dmi кладутся рядом с .dmm

Что это

Веб-версия конвертера dmm2xm из темы «Новая версия dmm2xm» на doom2d.org. Исходники Python (04.10.2026) не переписывались: в браузере их выполняет CPython, собранный в WebAssembly (Pyodide 0.27.7).

Обратная сторона пишет .dmm и инструменты .dmi. Прямая читает отдельный .dmm или песню из doom2d.wad / другого WAD. Пакет скачивается zip-архивом, внутри есть log.txt.

Открывать как file:// нельзя: воркеру нужен HTTP. Из папки сайта:

python3 -m http.server 8080

Затем http://localhost:8080 . Первый запуск тянет рантайм WASM с jsDelivr (~10 МБ), дальше его держит кэш браузера. Полное описание опций — в README_RU.txt автора.
